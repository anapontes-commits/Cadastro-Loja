# 🏪 Cadastro de Loja em Linguagem C

Este projeto é um programa simples desenvolvido em **linguagem C** para realizar o **cadastro de produtos de uma loja**, permitindo registrar nome, quantidade em estoque e valor de cada produto.

---

## 📋 Funcionalidades

- 📦 Cadastrar produtos
- 📄 Listar produtos cadastrados
- 📊 Controlar quantidade em estoque
- 💰 Informar valor do produto
- 🔁 Menu interativo no terminal

---

## 🧠 Conceitos utilizados

- Estruturas (`struct`)
- Vetores (arrays)
- Laço de repetição (`do while`)
- Estruturas condicionais (`if / else`)
- Entrada e saída de dados (`scanf` / `printf`)
- Constantes com `#define`
